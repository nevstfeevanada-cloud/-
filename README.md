# СЛКК||Слово лига королей Каменска

Русскоязычный сайт сообщества из Каменска-Уральского: тематические встречи, волонтёрские инициативы и поддержка школьников в вопросах буллинга.

## В проекте
- адаптивный сайт в тёмных фиолетовых и синих тонах;
- разделы о сообществе, мероприятиях и поддержке школьников;
- форма записи, которая включится после добавления события;
- демонстрационная панель организатора (`admin.html`).

## Локальный просмотр
Откройте `index.html` в браузере или запустите в папке проекта:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Сейчас это прототип
Список событий намеренно пуст: реальные даты и адреса пока не предоставлены. Не добавляйте вымышленные анонсы как настоящие.

Панель организатора и форма — только демо. Они используют локальное хранилище браузера и не передают заявки организаторам. На другом устройстве данные посетителей не видны. Панель не защищена паролем, поэтому не публикуйте её как рабочую админку и не используйте для реальных персональных данных. Перед настоящим запуском понадобится безопасный сервер для хранения заявок, вход для организатора и продуманная обработка данных. Не собирайте через форму личные истории школьников о буллинге.

## Публикация
Статический сайт можно разместить через GitHub Pages, но это не превратит демо-форму в реальную систему заявок. Сначала нужно подключить backend и защитить панель организатора.
